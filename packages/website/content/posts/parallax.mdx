Wer schon mal im Zug quer zur Fahrtrichtung aus dem Fenster die Landschaft hat vorbeiziehen lassen, kennt den Effekt:
Der Baum in der Nähe fliegt nur so vorbei, der Hügel in der Ferne scheint sich deutlich langsamer zu bewegen.

Relativ zum fahrenden Zug haben der Baum und der Hügel die gleiche Geschwindigkeit.
Aber je näher, desto höher die Winkelgeschwindigkeit, und das Hirn bastelt daraus verschiedene wahrgenommene Geschwindigkeiten.

Zeichentrickfilme, Computerspiele oder Webseiten nutzen den Parallax-Effekt quasi auf dem Rückweg:
Eine Grafik in verschiedene Ebenen aufteilen, die Ebenen relativ zueinander bewegen, und das Gehirn erfindet die Tiefeninformationen dazu.

Bei klassischen, gemalten Trickfilmen fällt unser Gehirn da seit fast 90 Jahren herein: Schon in Disney-Klassikern wie _Bambi_ gleitet der Blick durch einen Wald, der aus nichts anderem besteht als aus flachen, gemalten Ebenen.
[In diesem nerdigen Film](https://www.youtube.com/watch?v=YdHTlUGN1zw) aus den 1950er(!) gibt Walt Disney den Erklärbären für eine riesige Apparatur, in der bis zu sieben auf Glas gemalte Bildebenen übereinander lagen und unterschiedlich schnell unter der Kamera bewegt wurden.

## Ebenen

Zur Steuerung hab ich jetzt die Mausbewegung per Javascript in zwei Zahlen zwischen `-1` und `1` übersetzt.
Ich weiß also sowohl für die X als auch für die Y-Achse wo die Mause relativ ist.

Jetzt muss ich noch Ebenen aufbauen. Unten ein sehr einfaches Beispiel mit nur drei Ebenen.

Den Ebenen gebe ich eine CSS Prop [`--depth`](#depth). Eine markiere ich mich `-1` als hinten und eine mit `+1` als vorne.

Und stöpsele die aktuelle, normaliserte Mausbewegung auch als CSS Props ein: [`--parallax-x`](#parallax-x) und [`--parallax-y`](#parallax-y)

[Aus der Kombination von `-parallax` und `depth`](#css-calc) berechne ich dann in CSS wie weit ich die Ebene herrumschieben muss.

```tsx
<svg>
    <circle
        className={'red parallax'}
        cx="200"
        cy="125"
        r="100"
        style={
            {
                ['--depth' as string]: String(-1),
            } as CSSProperties
        }
    />
    <circle
        className={'yellow'}
        cx="200"
        cy="205"
        r="100"
    />
    <circle
        className={'blue parallax'}
        cx="200"
        cy="275"
        r="100"
        style={
            {
                ['--depth' as string]: String(1),
            } as CSSProperties
        }
    />
</svg>
```

```typescript
const doParallax = () => {
    const element = ref.current;
    const { x, y } = coordsRef.current;

    element.style.setProperty('--parallax-x', String(x));

    element.style.setProperty('--parallax-y', String(y));
};

useAnimationFrame(doParallax);
```

```css
.parallax {
    transition: transform 10ms ease;
    transform: translateX(calc(150px * var(--parallax-x) * var(--depth)))
        translateY(calc(150px * var(--parallax-y) * var(--depth)));
}
```
