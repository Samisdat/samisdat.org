# Star extract (stars.json)

This directory contains an extract of the **HYG database v4.4**
(Hipparcos, Yale Bright Star, Gliese), compiled by David Nash / Astronexus:
<https://codeberg.org/astronexus/hyg>

The HYG database combines data from the Hipparcos catalogue (ESA), the Yale
Bright Star Catalogue (Hoffleit & Jaschek) and the Gliese Catalogue of Nearby
Stars (Gliese & Jahreiss).

## Changes made to the original

- Reduced to stars with apparent magnitude 4.5 or brighter (925 stars); the Sun is removed.
- Reduced to four values per star: right ascension (converted from hours to degrees, epoch J2000),
  declination (degrees), apparent magnitude, colour index (B-V). Stars without a colour index get 0.5.
- Values rounded (angles to 3 decimals, magnitude and colour index to 2) and stored as a JSON
  array of arrays, sorted by magnitude, brightest first.

Generated by `pnpm generate:stars` in `packages/website`, which checks the SHA-256 of the source file.
